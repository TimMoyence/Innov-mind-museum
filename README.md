# Musaium

Compagnon culturel IA voice-first : photographier une œuvre ou un monument, en discuter avec l'IA, garder un carnet de visite.

- `museum-backend/` — API Node 22 + Express 5 + PostgreSQL (pgvector) + Redis
- `museum-frontend/` — app React Native + Expo
- `museum-web/` — site Next.js (vitrine, B2B, admin)

Démarrage : `pnpm bootstrap`, puis les commandes de chaque app dans `CLAUDE.md`.
